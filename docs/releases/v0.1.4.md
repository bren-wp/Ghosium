# Ghosium Browser v0.1.4 — compact native UI and Ghosium Search

- Reduced start-screen height, oversized branding and repeated shortcut panels; common actions now fit compact mobile displays more naturally.
- Kept five native bottom actions: back, forward, tabs, home, menu. No extra browser chrome above the Ghosium home/search panels.
- Keyword input now opens **native Ghosium Search results**, rather than a DuckDuckGo page. Source names remain attributed inside Ghosium cards.
- Added configurable Brendigo-operated SearXNG JSON search backend, with API keys strictly server-side. The `GHOSIUM_SEARCH_BASE_URL` GitHub repository variable enables general web search only after a reachable backend is deployed.
- Without a configured web backend, real search requests use the Croatian Wikipedia API and are **clearly labelled as limited encyclopedia results**; no claim of whole-web search.
- Secure HTTPS destination validation, explicit word-vs-URL routing, bounded JSON response size, query timeout and safe asynchronous UI updates.
- Added new destination classifier JVM tests.
- Maintains Android Lint, unit-test, APK/AAB build and SHA-256 checksums in GitHub Actions.

**Prerelease and limitations:** requires device screenshot/pixel parity tests, UI instrumentation, externally hosted search backend for full web coverage, and company upload signing keys for production. Until then GitHub releases include a debug APK and unsigned release AAB, not Play-ready artifacts. No isolated incognito or full ad/tracker blocking is claimed.
