# Ghosium Browser v0.1.2 — native screen implementation

### Android changes
- Original Ghosium ghost/compass launcher art; native Canvas aurora, mountains and lake used as an app background.
- Fully native Android Views for home, welcome, search, tabs, bookmarks, history, downloads, settings and browser security information.
- Real navigation, tab switching/closing, bookmark/history search, individual history deletion, downloads list sourced from DownloadManager, privacy controls and browser URL navigation.
- Saved tab URLs are restored after Android recreation; they reload rather than preserving full internal web state.
- Responsive ScrollView layouts for different phone screens and text sizes.
- HTTPS and WebView security behavior retained.

### Notes
- These are implemented native screens inspired by supplied designs, not screenshots used as fake interfaces. Pixel-perfect matching across every Android form factor still requires visual comparison with emulator/device captures.
- The browser uses Android System WebView; the web results page is served by DuckDuckGo. We do not hide or replace third-party content or trademarks.
- No genuine isolated incognito profile or full tracker blocker is claimed.
- This prerelease is not production-audited; test with a real device before consumer distribution.
- With no upload-signing secrets configured, release provides a debug APK for device testing and **unsigned release AAB** (not Play-ready), plus checksums.
