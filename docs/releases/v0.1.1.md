# Ghosium Browser v0.1.1

Ghosium-native homepage and search bar with Croatian wording. DuckDuckGo continues to supply web search results inside the Ghosium browser; the search index is not proprietary to Ghosium, and third-party content retains its own branding.

### Changes
- New Ghosium Search entry and direct browser navigation
- Native JavaScript/cookies privacy toggles; existing clear-data function
- Stronger HTTPS-only URL validation (schemes, embedded credentials, malformed hosts and ports)
- Expanded navigation regression tests
- Android versionCode 2, versionName 0.1.1
- Repeatable APK/AAB GitHub release workflow, checksums and optional upload-key signing

### Artifact status
- **-debug.apk**: signed with the Android debug key; for testing only
- **-release-unsigned.aab**: release build WITHOUT an upload signature; not ready for Google Play submission
- If upload signing secrets are configured, releases instead contain **-release-signed.apk** and **-release-signed.aab**

**Prerelease**: the browser is not yet production-audited; private mode, custom search results rendering, all design mockups and full device QA are not complete.
