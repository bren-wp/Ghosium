# Ghosium Browser v0.1.5 — stable native search & saved sessions

### Changes
- Search results now update **inside the current native Ghosium screen**. The query field, keyboard focus and scroll position no longer reset when the results arrive.
- Native retry control for unavailable search results; the source attribution remains visible.
- Faster browser chrome: one full-width omnibox on web pages (no duplicate home/open buttons); compact secondary screens without redundant large logos.
- Session restoration across **cold app starts** as well as Android Activity recreation: safely bounded to 8 tabs, disallowed schemes sanitized, only the selected page initially loaded.
- Native Ghosium error screens for blocked HTTP navigations, invalid TLS, Safe Browsing blocks and main-frame network failures, with appropriate home/retry actions.
- Common explicit HTTPS domain:port addresses supported while unsafe schemes remain blocked.
- Added session normalization and URL-routing unit tests.
- Android Lint, Gradle unit tests, debug APK, release AAB and GitHub automated release remain required.

### Search limitations
Ghosium has its own native results UI, but **does not have an independent crawler/index**. In the absence of a configured Brendigo-operated HTTPS SearXNG service, search is limited to Wikipedia and is labelled accordingly. No general web coverage is claimed.

### Distribution
The APK is debug signed for device testing. The release AAB is unsigned unless Ghosium upload signing secrets are configured, and cannot be uploaded to Google Play unsigned. This is a prerelease pending real-device QA, full visual parity checks and security review.
